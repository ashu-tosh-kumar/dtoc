## 2025-02-18 - Prevent ReDoS and Memory Exhaustion from DOM Parsing
**Vulnerability:** DOM-based Denial of Service (DoS) and Regular Expression Denial of Service (ReDoS) vulnerability. The extension parses `document.title` and `heading.textContent` directly from the DOM, and immediately passes these potentially very long strings to complex regular expressions for string replacement (like in `slugify` or the title sanitization block).
**Learning:** Maliciously crafted web pages can have extremely long values for `<title>` or heading tags (e.g. hundreds of thousands of characters). Passing these to regular expressions or string replacement loops can block the main thread, exhaust memory, and crash the browser or the extension. Because this is a browser extension executing content scripts on untrusted web pages, all DOM text extractions must be treated as untrusted input.
**Prevention:** Always enforce strict length limits (e.g., `.substring(0, 500)`) on user-generated text extracted from the DOM before performing CPU-intensive operations like regular expression replacements.

# Natively Supported Websites

This file is the single source of truth for websites natively supported by the DTOC extension. On these websites, the Table of Contents overlay is enabled by default in view mode.

## 1. Confluence Cloud
- **Pattern**: `*.atlassian.net`
- **Context**: Confluence wiki spaces and pages.

## 2. DEV Community
- **Pattern**: `dev.to` (and subdomains)
- **Context**: Tech articles and blog posts.

## 3. Medium (Official & Custom Domains)
- **Official Domains**: `medium.com` and its subdomains (e.g., `*.medium.com`).
- **Custom-Domain Publications**: The following popular publications hosted on Medium under custom domains:
  - `levelup.gitconnected.com` (Level Up Coding)
  - `plainenglish.io` (Matches all subdomains like `python.plainenglish.io`, `javascript.plainenglish.io`, `ai.plainenglish.io`, etc.)
  - `uxdesign.cc` (Matches `uxdesign.cc` and subdomains like `bootcamp.uxdesign.cc`)
  - `uxplanet.org` (UX Planet)
  - `betterprogramming.pub` (Better Programming)
  - `itnext.io` (ITNEXT)
  - `proandroiddev.com` (ProAndroidDev)
  - `writingcooperative.com` (The Writing Cooperative)
  - `ehandbook.com` (Entrepreneurship Handbook)
  - `entrepreneurshandbook.co` (Legacy Entrepreneur's Handbook domain)
  - `dailyjs.com` (DailyJS)

---
*Note: Any other websites not listed above are treated as unsupported by default. However, users can manually enable the Table of Contents on any website via the Site Quick-Toggle (Beta mode) in the extension settings popup.*
